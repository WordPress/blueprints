O que você pode fazer aqui?

  • Um espaço só seu — O WordPress está por trás de boa parte da web, mas aqui ele é só para você. Use como caderno de anotações, espaço para projetos ou um lugar para soltar a criatividade—não precisa publicar nada.
  • Totalmente personalizável — Troque o tema, organize tudo do jeito que preferir. Você vai aprender WordPress naturalmente enquanto usa.

O que você precisa saber

  • Está vinculado a este navegador — O seu Playground fica guardado no armazenamento deste navegador, então você não pode acessá-lo de outros dispositivos. Isso torna esse espaço bastante privado.
  • Faça backup do seu trabalho — Use o recurso de backup no menu superior para salvar o seu site. Assim você pode restaurá-lo em outro navegador ou se proteger contra a perda de dados do navegador.
  • Pronto para ir mais longe? — Leve o seu Playground para uma hospedagem WordPress dedicada para acessá-lo de qualquer dispositivo, compartilhar publicamente ou convidar pessoas específicas para colaborar.

O menu superior

Procure o ícone de grade () na barra superior. A partir dele você pode:

  • Instalar aplicativos — Selecionamos alguns plugins que funcionam bem para uso pessoal. O diretório completo de plugins do WordPress também está disponível caso queira explorar.
  • Backups — Salve e restaure o seu site
  • Começar do zero — Reinicie o seu WordPress ou acesse playground.wordpress.net para experimentos rápidos e temporários
